# Foundations and portable research: implementation plan

The user-approved direction is a branching curriculum, with independently
measured skill knowledge, composition and autonomous application. The 20-level
outline is a navigation sketch. Prerequisites and measured results determine the
actual graph. Grade 3 and grade 5 have individually testable subskills, rather
than one aggregate grade score.

## Fixed design decisions

- S³ owns definitions, independent assessment, curriculum, teaching artifacts and
  reports. BW owns the actual task runtime. PCC includes modified Strata plus COW
  and owns inference, contexts, native backprop, resources and candidates.
- Four independent difficulty coordinates; timing measured separately. Three
  qualification gates, fixed samples, critical checks and prior-success vetoes.
- Standard-library core; optional real Linux, BW, PCC and external application
  adapters. Models other than Wen can use evaluations and archives. Native
  training remains model/backend-specific.
- Inference thinking on/off and target-mask policy are independent. Default
  lesson targets are verified thinking, actions and answers. Answer/action-only
  is optional. Earlier context remains differentiable in ordinary backprop.
- Wen context maximum 131,072 tokens; compaction trigger 98,304; initial target
  32,768, with 49,152 and 65,536 comparison targets. Count exact rendered inputs,
  tools, thought/output budget and reserves. These are policies, not measured
  Wen capacity results.
- Morning recall, coherent subject blocks, evening questions and delayed returns.
  Initial long-run allocation: 50% focus, 30% retention, 20% composition. The
  timetable is simulated; no hour-long sleeps are needed to represent a class.
- Immutable original episodes, causal source-linked notes, explicit unresolved
  questions, search/rereading and delayed recall of details omitted from notes.
- Controlled research begins after its foundations. Hypotheses, controls,
  measurements, uncertainty and independent reproduction are required. A
  scripted reference story is a machinery fixture, not autonomous research.
- Preserve existing qualifications, model identities and controller budgets.
  No automatic training, promotion or replacement of active contexts.

## Implemented machinery being verified

The data catalog, DAG validation, exact bounded math/logic/state families,
independent grading, frozen three-gate assessment, difficulty coordinates,
interleaved schedule, immutable episodes, compaction/retrieval, multi-turn
exports, offline reports and guided exploration CLI are implemented.

Optional reference integrations exercise real Linux file/process effects,
BW's actual tool ledger, PCC's native CPU LoRA/full updates and the installed
Codex/OpenCode/Pi applications. The CPU-generated hybrid fixture exercises
16K/32K ordinary backprop and candidate reload. The research archive crosses
one million reference byte tokens with actual deterministic experiments and a
late return to an omitted source detail. Check the dated validation directory
for completed results and precise scope before making a claim.

## Gates still needed for live-model claims

1. CPU cookbook, installed-package checks, source review, documents and handoff
   passed at the dated checkpoint. Reference passes do not certify a model.
2. Obtain the human's machine-specific GPU window. Inspect capacity and use only
   the selected owned resource; retain headroom and record settlement.
3. Run paired Wen 1/1.1 foundation probes on matched profiles. Use the fixed
   qualification only for promising cells and with frozen critical/retention
   packs. First campaign: one authorized GPU at a time, four total GPU-hours.
4. Validate actual Wen contexts at 16K, 32K, 64K and 128K with its exact tokenizer
   and renderer. Compare compaction targets under measured budgets; refuse
   unsupported sizes instead of silently truncating. No YaRN extension claim.
5. Measure the same model through real BW/Codex/OpenCode/Pi tool workflows.
   Keep direct/tool-assisted and self/assisted retrieval ratings separate.
6. After required foundational gates, exercise live research stories and
   independently reproduce findings. Further graph cells, broader Linux admin,
   concurrency, specialized math/proofs and world environments need their own
   concrete fixtures and qualification. They remain planned where marked.
7. Only a later explicit training campaign may use approved practice lessons on
   Wen. Evaluate held-out transfer and preservation before any candidate choice.
