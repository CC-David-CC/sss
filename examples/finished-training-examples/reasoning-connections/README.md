# Reasoning connections: completed example artifacts

Strengthened by ideas incorporated from [LearnHarness](https://github.com/amosblomqvist/learnharness).
These are original, independently checked S³ practice conversations. No model
has been trained on these examples. No evaluation questions are included.

- [Joint premises](joint-premises/conversation.txt): all required facts must be established.
- [Premise change](premise-change/conversation.txt): prove the revised claim or produce a counterexample.
- [Reverse support](reverse-support/conversation.txt): select the smallest sufficient assumptions.
- [Method choice](method-choice/conversation.txt): pick the operation and compute the answer.
- [Interleaved day](interleaved-day/conversation.txt): switch to arithmetic, compact, then reread the original logic problem and revisit it with a withdrawn premise.

The immutable events and checker receipts accompany each TXT. The manifest binds
archive heads and TXT SHA-256 values. Compaction uses a short byte-counted
reference note; these are not Wen context measurements or model mastery results.
See [the guide](../../../docs/REASONING-CURRICULUM.md).
