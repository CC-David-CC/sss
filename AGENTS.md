# Skills³ ownership and evidence

S³ owns skill definitions, test suites, practice curricula and regression reports.
It does not own BW's task ledger, tool grants or publication decisions, or PCC's
model/context identities, native backprop, GPU leases or immutable candidates.
Keep the core importable without BW/PCC, NumPy, a GPU or a network connection.
Optional adapters must use the host's actual runtime and existing receipts.

Missing coverage and infrastructure failures are not model passes or model
training failures. Preserve original outcomes, candidate identities and bounds.
Never feed evaluation questions/answers into practice or silently relax a gate.
Keep raw private traces, credentials, models and machine handoffs out of Git.
Do not contact maintainers or publish outside the owner's authorized repository.
Do not add a license on the owner's behalf; retain notices for any reused code.

Use David <David@code.contractors> for author and committer and verify before
committing. Run actual builds/tests only on explicitly authorized hosts. Host
availability is not permission. Do not introduce another workflow runtime.
